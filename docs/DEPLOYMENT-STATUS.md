# 배포 진행 상태

대상 Firebase 프로젝트: `dvp1-8ab58` (사용자 지정). 사용자 배포 승인은 받았다. `.firebaserc`에 `production` 별칭을 저장했다.

현재 소스는 전체 테스트 58개 성공 기록과 일치한다. 운영 배포는 아직 실행하지 않았다.

배포 전 확인에서 Firebase CLI 프로젝트 조회가 인증 실패했다. 기존 ADC 파일의 존재와 SDK 초기화도 확인했지만 사용할 수 있는 Google 배포 인증으로 초기화되지 않았다. 자격증명 내용은 읽거나 출력하지 않았다. 현재 연결된 Google Cloud identity도 없다.

환경 설정에서 이 프로젝트에 배포 권한이 있는 Google Cloud 계정/identity를 연결해야 한다. 인증이 연결되면 프로젝트 및 기존 리소스, 요금제와 Auth 공급자를 조회하고, 등록된 웹 앱의 SDK 설정을 가져온 뒤 배포한다. 웹 앱이 여러 개면 대상 앱을 확인한다. 운영 데이터나 기존 Functions/인덱스의 삭제는 수행하지 않는다.

Firebase 웹 설정 4개는 현재 비어 있다. 인증 후 가능한 경우 SDK 설정을 자동 조회한다. 서비스 계정 키·토큰·로그인 인증 코드를 채팅에 보내지 않는다.
